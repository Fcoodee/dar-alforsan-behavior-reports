# تقارير الأداء السلوكي والأكاديمي — مدارس دار الفرسان

> **نسخة تجريبية ببيانات افتراضية بالكامل** (طالب 1 … طالب 179، وبريد `example.test`). لا بيانات حقيقية في هذا المستودع.

## جرّب فوراً (بلا تثبيت)
1. حمّل المستودع (Code ← Download ZIP) وفكّ الضغط.
2. افتح `index.html` بنقرتين (يلزم بقاء `data.js` و`access.js` و`assets/` بجانبه).
3. سجّل الدخول بحساب من `access.txt` (كلمات المرور عند المالك، ولا تُحفظ في المستودع).

## النشر على GitHub Pages
الإعدادات ← Pages ← Source: Deploy from a branch ← `main` ← `/ (root)`. يعمل الرابط `https://<المالك>.github.io/dar-alforsan-behavior-reports/`.
> ⚠ Pages ينشر الموقع **علناً** حتى لو كان المستودع خاصاً، فيصبح `access.txt` قابلاً للتنزيل لأي زائر. لا تضع فيه بيانات حقيقية، وأضفتُ `robots.txt` وعلامة `noindex` لتقليل الفهرسة فقط.

## الدخول (الوضع الحالي: قائمة منسدلة)
**كلمات المرور مجمَّدة مؤقتاً.** تسجيل الدخول باختيار نوع المستخدم من قائمة: الموجه، الوكيل، المدير، مدير النظام (وللموجه والوكيل تظهر قائمة المرحلة)، ثم زر «تسجيل الدخول». لا حماية فعلية: أي زائر يختار أي دور.
لإعادة الدخول بكلمات المرور (`access.txt`): افتح الرابط مع `?auth=password`، أو غيّر الثابت `LOGIN_MODE` في `index.html`.

## الصلاحيات بكلمات المرور (مجمَّدة، `access.txt`)
الصيغة: `المعرف,pbkdf2:التكرارات:الملح:البصمة,الدور,المرحلة,الاسم`. تُقرأ بدالة `fetch`، وإن تعذّر (فتح الملف مباشرة من الجهاز) تُستعمل نسخة `access.js`. تُولَّد بـ `node tools/make-access.js "المعرف|كلمة المرور|الدور|المرحلة|الاسم" ...`.

| الدور | يرى |
|---|---|
| موجه | طلاب مرحلته فقط |
| وكيل | موجه مرحلته وطلابها (يمكن مرحلتان بـ `middle+secondary`) |
| مدير المدرسة | الجميع |

لكل شخص معرّف مستقل (`dar0` و`dar1` للموجهين، `dep0` و`dep1` للوكيلين، `mgr` للمدير، `syseng` لمهندس النظام) ليميّز سجل التدقيق من فعل ماذا.

> ⚠ قفل في المتصفح وليس خادماً: الملف قابل للتنزيل، والبصمة لكلمة مرور قصيرة تُخمَّن دون اتصال. مناسب للتجربة ببيانات افتراضية فقط، ولا يصلح لحماية بيانات حقيقية (انظر `docs/HANDOFF.md`).

## ما يمكن تجربته
| المسار | كيف |
|---|---|
| عزل المراحل | موجه الابتدائي لا يرى فصول المتوسط، والمدير يرى 19 فصلاً |
| تحرير التقرير | اختيار عبارات حتى 4/4/3، وعبارة مخصصة ≤ 120 حرفاً، ومعاينة A4 فورية |
| سير العمل | الموجه **يرسل** ← الوكيل **يراجع ويعتمد** ← المدير **يعتمد أو يعيد للمسودة بسبب** ← نشر. التقرير مقفل بعد الإرسال |
| المتابعة | صندوق «المتابعة وفاعلية العمل على التقارير» يعرض كل مرحلة بدورك، وبجانب كل مستخدم أرقام تتغير: الموجه (أُرسل/متبقٍ)، الوكيل (بانتظارك/متبقٍ للاعتماد)، المدير (مرسَل/معتمد/بانتظارك) |
| ما ينتظرني | زر «بانتظار إجرائي» يعرض تقارير دورك المنتظرة عبر كل الفصول |
| الإعادة | تتطلب سبباً مكتوباً |
| التدقيق | زر «سجل التدقيق» |
| الطباعة | «طباعة / حفظ PDF» من المتصفح (A4) |
| تصفير | زر «تصفير التجربة» |

## البنية
- الجذر: تطبيق تجريبي يعمل محلياً (محاكاة تخزن في المتصفح `localStorage`).
- `apps-script/` الخلفية الحقيقية المقصودة (Google Sheets + Apps Script) — **لم تُختبر على Google بعد**.
- `design/` ملفات لوحة التصميم (Claude Design): `canvas.json` و`Main.dc.html` و`Report.dc.html`. روابط الصور فيها خاصة باللوحة.
- `tests/e2e.js` اختبار متصفح آلي (Playwright).
- `docs/HANDOFF.md` القرارات والحالة والأسئلة المفتوحة.

## الاختبار الآلي
```
npm i playwright && node tests/e2e.js
```
(يتطلب Chromium؛ حدّد `CHROMIUM_PATH` إن لزم. إخفاق تحميل خط Google في بيئة بلا إنترنت ليس خللاً في التطبيق.)
