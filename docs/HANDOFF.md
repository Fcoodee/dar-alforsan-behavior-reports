# HANDOFF — تقرير الأداء السلوكي والأكاديمي (دار الفرسان)

## الهدف
تقرير A4 لكل طالب في القسم الأهلي (ابتدائي، متوسط، ثانوي) بعبارات يختارها الموجه أو الوكيل، يمر بمراجعة واعتماد، ثم يُولَّد PDF ويُرسل رابطه لوليّ الأمر خارج النظام (Drive).
المسمى المقترح من المالك: «تقرير الأداء السلوكي والأكاديمي للعام الدراسي 1447-1448 هـ — الخطة العلاجية».

## الأدوار
| الدور | العدد | الصلاحية |
|---|---|---|
| موجه طلابي | 3 (واحد لكل مرحلة) | يكتب لمرحلته فقط |
| وكيل شؤون الطلاب | 3 (يحتاج تأكيداً: ابتدائي، متوسط، ثانوي) | يراجع مرحلته ويكتب |
| مدير المدرسة | 1 | يعتمد وينشر، ويرى كل المراحل |
| مدير النظام | 1-2 | يملك الشيت، يدير المكتبة والمستخدمين |

## القرارات
- **قاعدة البيانات:** Google Sheets، ملكه مدير النظام فقط ولا يُشارك مع المعلمين.
- **الوصول:** تطبيق ويب Apps Script مقيّد بدومين المدرسة؛ التصفية حسب المرحلة في الخادم عبر ورقة `Staff`.
- **سير العمل:** DRAFT ← SUBMITTED ← REVIEWED ← APPROVED ← PUBLISHED، وبعد الاعتماد يُقفل التقرير. إعادة الفتح بسبب مكتوب.
- **الحدود:** 4 قوة، 4 تحسين، 3 توصيات. العبارة المخصصة ≤ 120 حرفاً. تخزين **نص** العبارة (لقطة) لا مرجعها فقط.
- **التسليم:** PDF في Drive بأسماء معرّفات داخلية لا أسماء الطلاب. الرابط مفتوح أو مشارك مع بريد وليّ الأمر (قرار معلّق).
- **لا اقتراح آلي** لعبارات الطلاب، ولا تصنيف آلي. أي مساعد ذكي مستقبلاً يكون مسودة يعتمدها الموجه.

## الحالة
| البند | الحالة |
|---|---|
| منطق الصلاحيات والتقارير (`Code.gs`) | اختُبر على محاكاة محلية: 10 فحوص نجحت |
| على Google الحقيقي | **لم يُختبر** |
| توليد PDF (`testPdf`) | **لم يُختبر**، وهو القرار الحاسم لمسار التوليد |
| واجهة العمل الكاملة `web/index.html` | تعمل محلياً بمحاكاة؛ **اختُبرت في متصفح Chromium** (16 فحصاً ناجحاً: الأدوار، العزل، السقوف، سير العمل، القفل، التدقيق، PDF A4) |
| ربط الواجهة بـ Apps Script الحقيقي | **غير مُنجز**: الواجهة جاهزة لمحوّل `google.script.run` لكنه لم يُجرَّب |
| قالب الإخراج | A4 بترويسة دار الفرسان وشعارها خطوطاً في الخلفية؛ بلا ختم ولا توقيعات |

## أسئلة مفتوحة
1. عدد الوكلاء (3؟) وهل للثانوي بيانات طلاب.
2. المسمى النهائي («الخطة العلاجية» قد توصم الطالب؛ يُقترح فصلها عن تقرير الأداء العام).
3. العام الدراسي: «1447-1448» يطابق عاماً انتهى بحسب فهمي؛ تحقق من المعتمد.
4. رابط وليّ الأمر: مفتوح أم مشارك مع بريده؟ وتاريخ انتهاء الرابط.
5. مكتبة التوصيات: 3 فقط حالياً.
6. بقاء توقيع/ختم: حُذفا بطلب المالك؛ هل تلزم مساحة توقيع يدوي؟

## الخطوات التالية
1. المالك يشغّل `setup` و`selfTest` و`testPdf` على Google (انظر `apps-script/README.md`) ويرسل النتائج.
2. إن فشل PDF العربي: قالب Google Docs أو توليد خارجي.
3. ربط واجهة العمل الكاملة بالسكربت واستيراد المكتبة (40+40) والطلاب.
4. تجربة على فصل واحد، ثم التوسع.

## الخصوصية
بيانات قاصرين: نظام حماية البيانات الشخصية. أقل بيانات لازمة، سجل تدقيق (`Audit`)، ولا بيانات في Git أو في مستودع عام.
